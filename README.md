# MD Garage
Advanced Fivem Garage System


Garage System using 3D Vehicle Models for Preview, Interactive Colors, Vehicle Categories and more...


# Functions
- Engine & Body Damage & Fuel Level visible in garage menu
- Vehicle icon changes color based on Engine Health
- Vehicle 3D Model Preview in garage menu
- Rename vehicle (Configurable rename fee)
- Transfer vehicle to other players
- Create categories and add vehicles to them
- Store vehicle by targeting it with ox_target (Also works by targeting garage NPC)
- Configurable impound (Set impound fee, per hour on impound fee, maximum fee)
- Discord logs on every action
